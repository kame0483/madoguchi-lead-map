# 案件エリアマップ

既存の GitHub Pages + Supabase `lead-map-api` を継続する営業用画面です。

- フロント: https://kame0483.github.io/madoguchi-lead-map/
- 既存の `?k=...` 付き閲覧URLを使用してください。キーをコードやREADMEへ記載しないでください。
- `pref=岡山県` で県内表示、`pref=岡山県&city=岡山市北区&r=40` で周辺検索から開始できます。既存キーのパラメータに追加します。
- 地図表示が重なる場合は拡大、都道府県選択、47都道府県の件数一覧から選択できます。

## 集計

`estima_ingest_log` の `fn=lead`、`gaiheki`／`amamori` を対象とします。まず同一 `eid` の最新履歴を確定し、その後に有効／審査中、2025/12/01以降、地域条件を適用します。`eid` がなければ種別・申込日時・地域・住所のハッシュで重複除外します。同時刻の更新はログIDと行順で確定します。

全国・都道府県・市区町村・距離検索・一覧は `lead_map_dataset_v2` を共用します。最初に取得したスナップショット日時をページ分割にも渡し、閲覧途中の更新による合計のずれを防ぎます。「更新」で最新状態を取得します。日付の境界は日本時間、本日追加は受付日当日、直近7日は当日を含む7暦日です。

2026/11/13検証時: **5,237件 = 外壁4,979件 + 雨漏り258件**、本日16件、直近7日127件。旧5,321件には、最新状態が無効の84件が過去の有効履歴から混入していました。コードにこれらの案件数は固定していません。

8,123は管理画面の2026/11/13確認値であり、自動更新できる取得元は未接続です。案件数とは別の補助指標として確認日とともに表示します。

## 個人情報と認証

- APIはマスク済み電話番号だけを返します。メール・生の顧客オブジェクト・姓未分離のフルネームは返しません。
- 氏名は空白で姓を分離できる場合のみ表示します。判別できなければ「お客様」と表示します。
- 物件情報は許可リストの項目だけを返し、自由記述内の電話番号・メールもサーバー側で除去します。住所は依頼された仕様により表示します。
- RPCは `service_role` のみ実行でき、フロントから直接実行できません。新規関数は SECURITY INVOKER です。
- 既存の閲覧キー照合を維持。新しい画面はキーをAPIのヘッダーに渡し、APIリクエストURLへ追加しません。外部リソースへのRefererはoriginだけに制限します。
- 本番の `access-config.ts` は非公開のデプロイ設定です。公開リポジトリへ保存しないでください。`access-config.example.ts` は環境変数から読む設定例で、既存本番の値を上書きする手順ではありません。
- Edge Functionの再デプロイ時は、現在の非公開設定を保持し、`index.ts`、`access-config.ts`、`deno.json` を含めます。JWT検証は既存同様offで、関数内で閲覧キーを検証します。

現在の共通キーでは会社単位の識別・認可はできません。次段階は、会社ID・許可地域・有効期限をサーバー側で管理する失効可能な個別トークンです。URLの会社名だけを変更する方式では、会社の特定も閲覧権限の保護もできません。CTA計測はその識別基盤と合わせて追加してください。

## 画面・設定

- 初回は都道府県マーカーと集計のみ。市区町村座標は県ごとのJSONを必要な時に取得します。
- 距離検索では検索用の地名一覧と、円に接する都道府県だけを取得します。同名自治体は選択肢で確認し、ゼロ件を全国検索へ置き換えません。
- 全国・県内・周辺の案件一覧は50件ずつ取得。APIは空ページでも総件数を返します。
- APIの`cases`はPOSTの`keys`配列を推奨。従来GETも互換対応しています。120地域の切り捨ては廃止しました。
- Leaflet 1.9.4 / OpenStreetMapを継続。タイル取得が失敗した場合のみ地理院タイルへ切り替え、出典も更新します。
- 相談ボタンは現在メールです。正式URL決定後、`app.js` の `CALENDAR_URL` にHTTPSの予約URLを設定します。対応希望メールには案件ID・種別・エリア・住所・申込日時を挿入します。
- 会社別URL発行・会社別閲覧権限・CTAクリック計測・アクセスログは未実装です。

## 地理データ

`assets/geo/` は [code4fukui/localgovjp](https://github.com/code4fukui/localgovjp) の自治体代表座標（CC0）を県別に分割したものです。取得元CSVのSHA-256をindex.jsonへ記録しています。浜松市の中央区・浜名区は従来の中区役所・浜北区役所の代表座標を引き継ぎ、旧区名を更新しました。郡名・三宅島／八丈島の表記差を照合します。案件や顧客の住所データを含めていません。
